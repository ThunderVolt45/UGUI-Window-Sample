# 커밋 메시지 규약

이 프로젝트의 커밋 메시지는 한글로 작성하고, 변경 목적이 바로 보이도록 짧게 유지합니다. 태그와 코드 식별자는 영어 원문을 사용할 수 있습니다.

## 기본 양식

```text
[태그]: [작업 내용 요약 (50자 이내)]

[상세 내용 (선택)]
- (수정/추가한 파일): (작업 내용)
- (수정/추가한 파일): (작업 내용)

[이슈 번호] (예: Resolve #12)
```

- 제목은 `[태그]: 한글 요약` 형식으로 작성합니다.
- 상세 내용은 변경 파일과 이유를 빠르게 파악해야 할 때만 씁니다.
- 이슈를 닫는 커밋은 마지막 줄에 `Resolve #번호`를 적습니다.
- 클래스명, 메서드명, 파일명, API 이름은 원문을 그대로 씁니다.

## 상세 내용 예시

```text
Feat: 창 최소화 복원 이벤트 추가

- UGUIWindow.cs: 최소화 상태 변경 시 OnMinimizeWindow 호출 추가
- UGUIWindowManager.cs: 복원된 창의 z-순서 갱신 처리

Resolve #12
```

## 태그 목록

| 태그 | 용도 | 예시 |
| --- | --- | --- |
| `Feat` | 창 시스템, 에디터 도구, 샘플 앱의 새 기능 추가 | `Feat: 창 최소화 복원 이벤트 추가` |
| `Fix` | 버그 및 오류 수정 | `Fix: DPI 변경 후 리사이즈 위치 보정 오류 수정` |
| `Design` | UI/UX 레이아웃, 색상, 배치, 시각적 변경 | `Design: 설정 창 옵션 레이아웃 정렬 개선` |
| `Refactor` | 기능 변화 없는 코드 구조 개선, 중복 제거, 최적화 | `Refactor: 창 포커스 갱신 로직 정리` |
| `Docs` | README, 매뉴얼, 클래스 다이어그램 등 문서 작성/수정 | `Docs: CreateWindow 사용 예시 보강` |
| `Asset` | 프리팹, 씬, 스프라이트, `.meta` 등 Unity 에셋 변경 | `Asset: 데스크톱 작업 표시줄 프리팹 추가` |
| `Sample` | `Assets/UGUIWindowSample/Scripts/Sample/` 또는 샘플 씬 전용 변경 | `Sample: 기본 데모 창 생성 흐름 변경` |
| `Chore` | 프로젝트 설정, 패키지, 네이밍, 정리 작업 | `Chore: Unity 프로젝트 설정 갱신` |
| `CI` | GitHub Actions, 빌드/릴리즈 자동화 변경 | `CI: Windows 빌드 워크플로 수정` |

## 추가 예시

```text
Asset: 데스크톱 작업 표시줄 프리팹 추가

- UGUI_TaskBar.prefab: 작업 표시줄 레이아웃 구성
- UGUI_TaskBar.prefab.meta: 프리팹 메타 파일 추가
```

```text
Docs: 커밋 메시지 규약 정리

- CommitMessages.md: 한글 커밋 메시지 양식과 태그 목록 추가
```

## 작성 규칙

- 한 커밋은 하나의 목적만 담습니다.
- 제목의 작업 요약은 가능하면 50자 이내로 씁니다.
- 제목과 본문은 한글로 작성합니다.
- Unity 에셋을 추가하거나 옮길 때는 `.meta` 파일을 함께 커밋합니다.
- 프리팹과 클래스 이름은 창 로드 규약과 연결되므로 이름 변경 커밋은 상세 내용에 이유를 적습니다.
- public API나 프리팹 이름 규약을 깨는 변경은 제목 또는 본문에 `호환성 깨짐`을 명시합니다.

```text
Feat: 창 프리팹 로드 경로 변경

호환성 깨짐: 창 프리팹 탐색 경로를 Resources/Windows에서 다른 경로로 변경
```

필요한 설명이 길어지면 제목 아래에 빈 줄을 두고 본문을 추가합니다.
